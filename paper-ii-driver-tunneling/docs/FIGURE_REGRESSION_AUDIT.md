## Automated verification

After running the five Python figure generators, execute:

```bash
python paper-ii-driver-tunneling/checks/verify_figure_regressions.py
```

This checks model values against fixed manuscript/log benchmarks and confirms that the expected PDF and PNG outputs have valid signatures and reasonable dimensions. It does not compare PDF glyphs, plot labels, captions, layout, or embedded TikZ source with the compiled manuscript. Numeric tolerances reflect ordinary floating-point sparse solver differences; **certification of strict signs** remains the responsibility of `reproduce/certify_M10_parity.py` and its rational-residual verification note.
